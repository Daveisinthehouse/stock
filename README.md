# Stock — Office Orders

A tiny retro office game that runs in any modern browser. No dependencies or build step required.

## Play

Open `index.html` locally, or enable GitHub Pages for this repository and visit the published site.

Choose Sean, Niamh, or Emma, then press **Choose player** to start a 60-second shift. Press **Place order** as many times as you can.

- Sean and Niamh receive **ORDER PLACED!** and earn one point per order.
- Emma receives **WRONG ORDER!** and earns no points.
- At the end of the shift, your score is shown. Choose another player to play again.

## Files

- `desktop.png` — the pixel-art computer scene used as the game screen.
- `sean.png`, `niamh.png`, `emma.png` — the player character portraits.
- `index.html` — the complete game.

## GitHub Pages

In the repository settings, set **Pages → Build and deployment → Deploy from a branch**, choose `main` and `/(root)`, then save. The game will be served from the repository's root.
