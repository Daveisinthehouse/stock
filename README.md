# Stock — Toner Orders

A tiny retro office game that runs in any modern browser. No dependencies or build step required.

## Play

Open `index.html` locally, or enable GitHub Pages for this repository and visit the published site.

Choose Sean, Niamh, or Emma, then start the 60-second shift. The computer displays a customer from the supplied customer export and says **PLACE TONER**. Press **Place order** to process as many orders as you can.

- Sean and Niamh see a green tick with **ORDER PLACED** and earn one point per order.
- Emma sees a red X with **WRONG ORDER** and earns no points.
- The game shows the final score when the timer ends.

## Files

- `desktop.png` — the pixel-art computer scene used as the game background.
- `sean.png`, `niamh.png`, `emma.png` — the player character portraits.
- `index.html` — the complete game, including the customer list.

## GitHub Pages

In the repository settings, set **Pages → Build and deployment → Deploy from a branch**, choose `main` and `/(root)`, then save. The game will be served from the repository's root.
